状態: **骨子の段階。** 各章は「目的、見出し、現時点で分かっていること、未決事項」のみ。本文は未作成。

入力: [../ideas/](../ideas/README.md)(overview、ideas、scratch、design)、[../output.md](../output.md)、[../../rule/rule.md](../../rule/rule.md) 5.2。

## 前提と決定事項

- 位置づけは「旅の同行者探し」。主顧客は自治体。 [決定、旧 design.md 1.2 ほか]
- 競技ルール: localhost 完結、外部API/DB/クラウドへの実行時依存なし、ダミーデータ使用、ログイン不要。 [決定、rule.md 3・6・7]
- 機能の柱は 12 件(02 章)。**窓口の提案であり、オーナー未確定。**

- [決定]: 合意済み / [案]: 検討中の案 / [未決]: 決める必要がある / [要確認]: 事実確認が必要
- [事実]: 資料・コードで確認できたこと / [推定]: 推測(既存サイトはログイン前の静的解析のみ)
