# 08 外部リソース・OSS・ライブラリ一覧とライセンス

## 目的
利用した外部リソース、OSS、ライブラリの出所とライセンスを一覧にする(rule.md 8 の要件)。

## 含める内容
- ライブラリ一覧(名称、バージョン、ライセンス、用途)
- 地図、フォント、画像、アイコンなどの外部リソースと出典表記
- 生成AIが出力したコードの扱い

## 現時点で分かっていること
- 利用物は発信元とライセンスが明確なものに限る。強いコピーレフトは条件を満たせない場合採用しない。 [決定、rule.md 8]
- 商標、ロゴ、画像、フォント、音源を無断使用しない。 [決定]
- 地図は国土地理院タイル等、出典表記が必要。Google Maps 等は事前許可なしに使わない。 [決定]
- 既存サイト(Raund)の資産(ロゴ、コード)を流用してよいかは確認していない。 [要確認]
