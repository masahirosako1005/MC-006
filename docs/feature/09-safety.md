# 09 安全(公開範囲・通報・ブロック・禁止表現・本人確認モック)

## 1. 概要と責務 / 対応する柱
- 柱5(プロフィール公開範囲)、6(通報・ブロック)、7(本人確認・18歳確認のモック)、8(禁止表現・性別絞り込み禁止)。他モジュールが呼ぶ共通のガードを提供する。 [案]
- 規制方針(12 #2)、本人確認の水準(#3)、グループでの適用(#10)は未決。以降は暫定。

## 2. 既存機能との関係
- 新規(利用者間関係は既存になし)。競技はログイン不要のため、本人確認はモック表示。

## 3. 画面・UI(04 章)
| 画面 | 04 章の項目 | パス案 |
|---|---|---|
| プロフィール編集(公開範囲) | プロフィール編集 | `/[campaign]/mypage/profile` |
| 通報・ブロック | 通報・ブロック | メンバー一覧/承認画面/チャットから |
| 本人確認・18歳確認(モック) | 本人確認 | 初回の参加申請前 |

## 4. データ(05 章)
| エンティティ | 項目 | 保存先 |
|---|---|---|
| Profile | 表示名、年代帯、一言、旅の目的、項目別公開範囲 | seed(ダミーユーザー)+Store |
| Report / Block | 対象、種別、内容、対応状況、ブロック関係 | Store |
| Verification | 確認結果のみ(モック) | Store |

## 5. インターフェース(案)
| 名称 | 入力 | 出力 | 呼び出し元 |
|---|---|---|---|
| `visibleProfile(viewer, target, context)` | context=一覧/申請/メンバー | 公開範囲内の項目 | 02、03、01 |
| `isBlocked(a, b)` | - | boolean | 02、03、06 |
| `report(user, target, reason, body)` / `block(user, target)` | - | 受付結果 | 画面 |
| `checkText(text, field)` | 文字列 | OK または禁止語の理由 | 全入力(01、03、05、06、07) |
| `requireVerified(user)` | - | 未確認なら AppError | 03 |
| `memberSummary(members)` | - | 年代帯分布(少人数丸め) | 02 |

## 6. 状態遷移
- 通報: 受付 → 対応中 → 完了(デモは受付のみ [案])。ブロック: 有効 ↔ 解除。

## 7. 入力検証・セキュリティ
- 禁止表現: 恋愛・異性交際を連想させる語、連絡先交換の誘導などの辞書(ローカル、自前 [案])。性別・年齢での絞り込み項目は API・画面に設けない(静的に検査する試験を用意)。
- 公開範囲は「表示側(サーバー)」で適用し、API 応答に非公開項目を含めない。承諾前は本名・連絡先を返さない。
- 通報本文は長さ制限・エスケープ。ブロックは双方向に効かせるか自分側のみか [未決 #8]。

## 8. エラー処理
| コード | 条件 | 表示 |
|---|---|---|
| invalid_input | 禁止表現 | どの語がどの欄で不可か、言い換え案 |
| forbidden | 未確認・18歳未満(モック) | 確認手順 |
| blocked | ブロック関係 | 相手に伝わりにくい一般文言 |

## 9. 試験観点(10 章)
- 承諾前に連絡先が見えない、18歳未満は進めない、ブロック後に一覧・チャットに出ない、禁止表現が画面・データに出ない、性別絞り込みが無い。
