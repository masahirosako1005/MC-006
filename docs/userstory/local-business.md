# 地元事業者(協賛・送客先)側の価値

根拠: [ideas.md](../ideas.md) 7.6(協賛・送客手数料)、5.6(交通・宿泊事業者との連携)、[design.md](../design.md) 1.2、[overview.md](../overview.md)(スポット・クーポン・特典)。
注意: docsに事業者のペルソナ・ユーザーストーリーは**書かれていない**。以下は、docsの収益構造と既存機能から本書が整理した**提案・仮説**。

## ペルソナ(仮説)

**地元の店・宿・体験事業者・交通会社**: ラリーのスポットや特典として参加し、来客を得たい。docsは「来客の成果を示せることが条件」としている(7.6)。ペルソナP2(ケンジ)が店主として重なる場合もある。

## ユーザストーリ(提案)

### US-B1 スポット・特典として参加し、来客を得る
- ストーリー: 地元事業者として、ラリーのスポットや特典に自店を載せたい。なぜなら、来訪者を増やしたいから。
- 体験価値: 既存のスポット登録、スタンプ獲得、クーポン(スタッフに画面を見せ右スワイプで使用)で来店導線ができる。
- 関連機能: スポット、クーポン、特典(既存流用)

### US-B2 成果を数字で確認する
- ストーリー: 地元事業者として、送客の成果(来店数など)を確認したい。なぜなら、協賛の費用対効果を判断したいから。
- 関連機能: 計測(既存タグの拡張、集計画面は新規)。成果の定義・計測方法は未決。

### US-B3 リピート客と関係を持つ
- ストーリー: 地元事業者として、旅行者と継続的に関係を持ちたい。なぜなら、その場限りで終わらせたくないから。
- 関連機能: 同行枠・おすすめ紹介(local-host.md の US-H2/H3 と共通)、通知

## 価値の要約(スライド1枚用)

1. ラリーのスポット・特典として、来客導線を得られる(提案)。
2. 成果を示せる形で協賛でき、費用対効果を判断できる(提案、計測方法は未決)。
3. 出会いを軸にした再訪で、リピート客の可能性が広がる(仮説)。

## 確認事項(このファイル固有)

- 事業者の参加動機、協賛の料金体系、手数料の対象(来店、予約、販売)は docs に無い。
- 宿泊・交通の販売は旅行業法の確認が必要で、設計の対象外案(design.md 1.3)。送客手数料の範囲が旅行業法に触れないかは未確認。
