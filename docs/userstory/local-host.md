# 地元の人(協力者)側の価値

根拠: [ideas.md](../ideas.md) 4章(P2)、エピック B、G-16、[scratch.md](../scratch.md) 2.2。
担い手の動機・有償無償は**未決**(design.md 2章 #5)。

## ペルソナ(ideas.md P2)

**ケンジ(41歳、地方都市の飲食店経営)**: 外から来る人と話し、地域を知ってもらいたい。観光客はその場限りで終わることが多く残念。手間や責任が重くなる関わり方は避けたい。

## ユーザストーリ

### US-H1 無理のない負担で参加する
- ストーリー: 地元の人として、可能な日時・回数・内容を自分で決めて参加したい。なぜなら、無理なく続けたいから。(B-3 / M)
- 体験価値: 負担を自分でコントロールでき、続けやすい。
- 関連機能: 同行できる枠(HostSlot)の登録(日時、回数、内容、定員)

### US-H2 地域の魅力を紹介する
- ストーリー: 地元の人として、地域の魅力を伝えるスポットや話題をラリーに登録したい。なぜなら、外の人に地域を知ってもらいたいから。(B-4)
- 体験価値: 自分の店・おすすめが、旅行者の目的地になる。
- 関連機能: 紹介スポット登録(スポット管理の拡張。管理手段は未確認)

### US-H3 旅行者と一緒に回る枠を出す
- ストーリー: 地元の人として、旅行者との同行枠を提供したい。なぜなら、その場限りで終わらず、また来てくれるつながりを作りたいから。(G-16, B-2)
- 体験価値: 一度きりの接客が、継続的な関係に変わる可能性。旅行者が少なくても成立する枠にもなる。
- 関連機能: 同行枠、同行の希望・承諾

### US-H4 不安な申込は断る
- ストーリー: 地元の人として、不快な相手や不安な申込を断りたい。なぜなら、安全に参加し続けたいから。(B-5 / M)
- 関連機能: 承諾・断り、ブロック、通報

## 価値の要約(スライド1枚用)

1. 「その場限り」の接客が、顔の見える再訪につながる。
2. 日時・回数・内容を自分で決められ、負担を抑えて続けられる。
3. 自分のスポット・おすすめが旅行者の目的地として紹介される。
4. 断る・ブロックする権利があり、安全に参加できる。
