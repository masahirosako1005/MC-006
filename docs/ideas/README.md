# docs/ideas/ について

設計書(`docs/design/`)を作る前のアイデア・検討メモ・事前調査を置く。**ここの内容は設計の確定ではない。** 確定した内容は `docs/design/` に反映する。

| ファイル | 役割 |
|---|---|
| [overview.md](./overview.md) | 既存サイト(Raund)の事前調査結果 |
| [ideas.md](./ideas.md) | 構想、ペルソナ、ユーザーストーリー、集客導線、法規制の整理、収益構造 |
| [scratch.md](./scratch.md) | 既存サイトの設計情報の起こしと、追加すべき機能・データの差分 |
| [design.md](./design.md) | 設計書に反映すべき事項(決めること、機能の優先度、章立て案)のメモ |

成果物の定義は [../output.md](../output.md)、設計書の骨子は [../design/README.md](../design/README.md)。
