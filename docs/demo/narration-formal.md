# ナレーション原稿(丁寧語版・元の台詞)

口語版(narration.md)に切り替える前の台詞。使うときは、この行を narration.md の同じ ID の行と差し替える(または speak.ps1 の -Text に渡す)。

- [N0] これは、N西市のスタンプラリーに、グループ旅行をつなぐデモです。人物も地名も、すべて架空のデモデータです。
- [N1] まず、旅行者が幹事になって、グループを作ります。名称、行き先、日程、締切を入れて、地方を選ぶと、日本地図で場所が光ります。
- [N2] 氏名や連絡先を入れる欄はありません。作成すると、募集中のグループができます。
- [N3] そこへ、別の旅行者が二人、参加を申請しました。申請には、最少人数でも参加するという同意が必要です。幹事は、申請を見て承認します。
- [N4] 最少人数に達しました。人数が足りなければ中止、集まれば実行へ。この流れは自動で進み、幹事の手間を減らします。
- [N5] 次は、宿のオーナーの画面です。過去の実績と、これからの予定が、一つの棒グラフで見えます。斜線の棒が、グループ旅行の予定です。
- [N6] 週を選ぶと、年代別の円グラフに変わります。旅行が集中する週に、席や部屋を用意する、といった提案も出ます。事業者は、仕入れや人員を、前もって調整できます。
- [N7] 最後は、自治体の画面です。グループの作成数、申請数、実行確定率が、地方別にわかります。
- [N8] 五件未満の値は、少数と表示します。個人が特定されない形で、旅行者の動きを、政策に活かせます。担当地方だけを集計し、流入元もわかります。
- [N9] 旅行者には仲間を、事業者には来訪の見込みを、自治体には安心できる集計を。以上です。
