# ナレーション原稿(3分版・口語版)

`speak.ps1 -Id <ID>` が、下の `- [ID] 台詞` の行を読み上げる。既定の声は **VOICEVOX のずんだもん(ノーマル、style id 3)**。変更は `-Speaker "春日部つむぎ"`(名前または style id。一覧は `-ListSpeakers`)。VOICEVOX が応答しなければ Microsoft Haruka(SAPI)に自動で切り替わる。
**クレジット(必須)**: VOICEVOX の規約により、デモ画面の隅かスライドの最後に「音声: VOICEVOX:ずんだもん」と表記する(声を変えたら、そのキャラ名に変える。規約: https://zunko.jp/con_ongen_kiyaku.html、商用・非商用とも、クレジット表記で利用可。他キャラは配布元 https://voicevox.hiroshiba.jp/ で要確認)。
台詞は、親しみやすい口語(です・ます)。元の丁寧語版は [narration-formal.md](narration-formal.md) に残してある。読みの注意: サービス名「Kopa」は、台詞ではひらがな「こぱあ」で書く(画面・文書では「Kopa」。「こぱー」だと読みが「こ」「ぱー」に割れるため、長音を「あ」にした。VOICEVOX の audio_query で、アクセント句が「コパア」1 つになることを確認)。件数は漢数字、記号・英字は台詞に入れない。
台詞は**文単位に細分**してある(N3a、N3b…。通し番号 N0〜N9 のまとまりは、見出し行に残す)。operation.md 第4章は「操作 → 台詞(同期再生)」の直列なので、台詞を直したら、第4章の手順表と対応表も見直す。デモ用の架空データであることは N0 で断る。

## 第1部 グループの作成と参加

N0(導入)
- [N0] はじめまして。今日ご紹介するのは、こぱあ。観光だけじゃなく、地方の街と人、そして人と人を、つなぐことをテーマにしたサービスです。人物も地名も、すべて架空のデモデータですよ。

N1(グループ作成。入力 → 地方選択)
- [N1a] では早速、グループを作りましょう。
- [N1b] 名前と行き先、日程を入れて、地方を選ぶと、
- [N1c] ほら、日本地図の中部が光りました。

N2(作成)
- [N2a] ここがポイント。氏名や連絡先の欄は、ありません。
- [N2b] これで、募集中のグループができました。

N3(申請 → 承認)
- [N3a] 別の旅行者が二人、参加を申請してくれました。
- [N3b] 最少人数でもいい、という同意つきです。
- [N3c] 幹事は、承認を押すだけ。

N4(最少人数到達)
- [N4a] あっという間に、最少人数に達しました。
- [N4b] ここから先は自動で進みます。幹事の手間は、ぐっと減りますね。

## 第2部 観光事業オーナー(u-013)

N5(棒グラフ)
- [N5a] 続いて、宿のオーナーの画面です。
- [N5b] 青い棒が過去の実績、斜線の棒が、これからのグループ旅行の予定です。

N6(週の切替 → 円グラフ → 提案)
- [N6a] 週を選ぶと、年代別の円グラフに変わります。
- [N6b] 混みそうな週には、部屋や席を用意しましょう、という提案も出ます。

## 第3部 自治体(u-009)

N7(指標)
- [N7a] 最後は、自治体の画面です。
- [N7b] 作成数、申請数、実行確定率が、地方別にひと目でわかります。

N8(少数 → 流入元)
- [N8a] 五件未満の値は、少数と表示して、個人が特定されないようにしています。
- [N8b] 担当の地方だけを集計して、流入元もわかります。

N9(結び)
- [N9] こぱあは、旅行者に仲間を、事業者に来訪の見込みを、自治体に安心できる集計を。ありがとうございました。
