# ナレーション原稿(3分版・口語版)

`speak.ps1 -Id <ID>` が、下の `- [ID] 台詞` の行を読み上げる。既定の声は **VOICEVOX のずんだもん(ノーマル、style id 3)**。変更は `-Speaker "春日部つむぎ"`(名前または style id。一覧は `-ListSpeakers`)。VOICEVOX が応答しなければ Microsoft Haruka(SAPI)に自動で切り替わる。
**クレジット(必須)**: VOICEVOX の規約により、デモ画面の隅かスライドの最後に「音声: VOICEVOX:ずんだもん」と表記する(声を変えたら、そのキャラ名に変える。規約: https://zunko.jp/con_ongen_kiyaku.html、商用・非商用とも、クレジット表記で利用可。他キャラは配布元 https://voicevox.hiroshiba.jp/ で要確認)。
台詞は、親しみやすい口語(です・ます)。元の丁寧語版は [narration-formal.md](narration-formal.md) に残してある。読みの注意: 「エヌにしし」はひらがな混じりで表記(「N西市」は「エヌサイチ」と読まれる)、件数は漢数字、記号・英字は台詞に入れない。
台詞を直したら、operation.md の第4章「タイミング表」の所要秒も見直す。デモ用の架空データであることは N0 で断る。

## 第1部 グループの作成と参加

- [N0] はじめまして。エヌにししのスタンプラリーに、グループ旅行をつなぐデモです。人物も地名も、すべて架空ですよ。
- [N1] では早速、グループを作りましょう。名前と行き先、日程を入れて、地方を選ぶと、ほら、日本地図の中部が光りました。
- [N2] ここがポイント。氏名や連絡先の欄は、ありません。これで、募集中のグループができました。
- [N3] 別の旅行者が二人、参加を申請してくれました。最少人数でもいい、という同意つきです。幹事は、承認を押すだけ。
- [N4] あっという間に、最少人数に達しました。ここから先は自動で進みます。幹事の手間は、ぐっと減りますね。

## 第2部 観光事業オーナー(u-013)

- [N5] 続いて、宿のオーナーの画面です。青い棒が過去の実績、斜線の棒が、これからのグループ旅行の予定です。
- [N6] 週を選ぶと、年代別の円グラフに変わります。混みそうな週には、部屋や席を用意しましょう、という提案も出ます。

## 第3部 自治体(u-009)

- [N7] 最後は、自治体の画面です。作成数、申請数、実行確定率が、地方別にひと目でわかります。
- [N8] 五件未満の値は、少数と表示して、個人が特定されないようにしています。担当の地方だけを集計して、流入元もわかります。
- [N9] 旅行者には仲間を、事業者には来訪の見込みを、自治体には安心できる集計を。ありがとうございました。
